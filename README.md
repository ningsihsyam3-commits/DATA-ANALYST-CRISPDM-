# Analisis Data Pasien XYZ Medical Services

Project ini mengikuti workflow CRISP-DM untuk peran Data Analyst (Remote).  
Tujuan: mengubah data pasien dan operasional menjadi insight bisnis yang actionable.  

## Workflow CRISP-DM

1. **Business Understanding**
2. **Data Understanding**
3. **Data Preparation**
4. **Modeling**
5. **Evaluation**
6. **Deployment**

## Struktur Folder
- `data/`: data mentah dan hasil pemrosesan
- `notebooks/`: notebook analisis tiap fase
- `src/`: script automation
- `reports/`: laporan dan dashboard akhir
- `docs/`: dokumentasi tiap fase

## Cara kerja
- Task tiap fase didokumentasikan di folder `docs/`
- Analisis dilakukan dengan notebook dan script di `src/`
- Workflow otomatis dengan GitHub Actions di `.github/workflows/`
